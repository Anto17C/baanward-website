# Baanward brand assets

- baanward-primary: garden green #35493E with terracotta #9B503A dot.
- baanward-light: ivory #FFFAF0 with pale clay #E0BB94 dot, for dark backgrounds.
- baanward-monochrome and baanward-white: single-colour wordmarks.
- baanward-mark and baanward-mark-monochrome: transparent b. marks.
- baanward-social-profile: light b. on a green square, safe for circular cropping.

Each logo has SVG, PNG and lossless WebP versions. Wordmark raster exports are 2400px wide; compact marks are 1024px square. All wordmarks and standalone marks have transparent backgrounds. SVG lettering is outlined, with no external font dependency. Based on the site's Inter SemiBold with adjusted spacing; licence: ../../fonts/LICENSE.txt.

Browser assets: favicon.svg, favicon.ico (16/32/48px), favicon-16x16.png, favicon-32x32.png, apple-touch-icon.png (180px), android-chrome-192x192.png and android-chrome-512x512.png.

Use SVG for scalable artwork and PNG for documents or uploads. Preserve proportions and clear space. Keep taglines separate. Use light or white versions on dark backgrounds.

Prepared assets only: existing website wordmarks and favicon references have not been changed.
